# Unseen
Lightweight staff vanish for Paper 1.21+/26.x. `/vanish`: invisible to non-staff (permission `unseen.see` sees you), optional fake leave/join broadcasts, silent real join/quit, no pickup, no mob targeting, invulnerable, action-bar reminder, state persists across relogs and restarts. One jar, no dependencies.

## Tested on
Paper 1.21.11 and Paper 26.2 (runtime-tested, not just "it loads").
